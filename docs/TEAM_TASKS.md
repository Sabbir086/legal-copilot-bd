# Development ownership

This is a two-party development workflow for the Legal Copilot prototype:

- Assistant: prepare architecture, code changes, tests, documentation and troubleshooting instructions.
- User: run local commands, manage their own API keys/accounts, provide execution output and approve external account connections/actions.

The project must remain explainable. The user should understand the agent roles, source-verification flow and limits before a demo or technical review.
